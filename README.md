# food-inventory
Android-based app which scans/records food item barcodes and expiration date into a SQLite dbase.
Quantity values & a search function included.
Rev 1.1 Added delete function independent of barcode scan.
Rev 1.2 Updated app name and icon.
Release PantryPal MVP with backup import/export.
Rev 1.2.1 Added shopping list generator.

## Current Features

- Rapid barcode scanning with Quick Scan mode
- Manual/Bluetooth barcode input support
- Category-based expiry suggestions
- Automatic storage-location defaults
- Unknown product naming and local barcode memory
- Inventory editing via Product Detail screen
- Zero-stock retention for shopping list generation
- Dedicated shopping list with manual additions and checkboxes
- CSV import/export
- Expiry notifications
